# Anya v0.2.31

相较 **v0.2.30**，本版整理 Diff 与代码读取侧栏，减少长对话流式渲染和多文件差异占用，并完善桌面与手机端的会话、工作区及默认设置同步。

### 修复与改进

- **连续多文件 Diff**：在同一滚动区域依次查看多个文件；文件树点击后跳转到对应文件，窄侧栏自动收起文件树，也可手动切换。离开差异页或滚远后卸载差异正文，保留文件标题与占位高度。
- **代码读取预览**：侧栏增加自动换行开关；读取时片段与当前文件不一致时，可切换查看当前文件上下文，原始快照仍保留。
- **流式交互**：减少时间线在每次增量更新时的重复复制与拼接；流式 Markdown 在空闲时段解析，完成后立即渲染，降低 Agent 输出期间的界面阻塞。
- **手机端同步**：按成功读取活动 ID 提供受控的当前代码预览；同步归档工作区状态及新对话所需的模型、模式与权限默认项，不发送完整设置或密钥。

### 说明

- 手机端当前文件预览及桌面默认项同步需要配套版本的 Anya Companion；旧版 Companion 不使用这些新接口。
- 自动更新仍需上传同版本的 `Anya_0.2.31_x64.msi`、`.msi.sig` 与 `latest.json`。本说明文件不代表安装包或更新 JSON 已生成。

手机端项目：[AnyaAndroid](https://github.com/rururunu/AnyaAndroid)。发布流程见 [发布与远程更新](../docs/release.zh-CN.md)。
