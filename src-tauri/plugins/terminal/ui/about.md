# Terminal

Anya 官方终端。每个**对话**各自占一个 PowerShell 进程：切到另一个会话时，这边的终端还在，不会串台。

起始目录是**当前对话所属工作区**；没有工作区时用 Anya 用户目录。点工具条上的刷新，会按此刻的工作区目录重新开一个进程。

## 能做什么

- **资料区终端**：右侧工具条点终端图标打开。输入、输出、当前目录都跟这个对话绑定。
- **刷新**：杀掉当前对话的进程，再在该对话工作区根目录重新连接。
- **外观**：本页「设置」可选本机字体和字号，所有已打开的终端立刻跟上。
- **Agent**：对话里的 `plugin_terminal__run` 是一次性短命令，**不是**这个侧栏会话。

## 和系统终端的区别

侧栏里是嵌在 Anya 里的 ConPTY + xterm。如果要弹出 Windows Terminal / 系统 PowerShell 窗口，用工作区右键菜单里的「在终端中打开」。

## 权限

| 权限 | 用途 |
| --- | --- |
| `pty` | 为本机打开真实终端进程 |
| `run` | Agent 执行短命令 |
| `ui.workbench` | 把终端挂到工作台资料区 |
| `agent.tools` / `agent.prompt` | 注册 Agent 工具与说明 |
| `storage` | 记住字体设置 |

停用后侧栏入口会消失，各对话的终端进程一并结束。字体偏好仍留在本机。
