# 权限与代码预览

[English](./permissions-and-preview.md) · 适用于 Anya v0.2.28。

## 权限范围

聊天模式（Ask / Agent / Plan / Image）与权限范围独立。Plan 审批和工具专属限制仍是额外检查。

| 界面权限   | 持久化值      | 行为                                                                  |
| ---------- | ------------- | --------------------------------------------------------------------- |
| 只读       | `ask`         | 拒绝文件修改及任意 Shell 执行，用户审批不能提升权限。                 |
| 工作区写入 | `auto`        | 允许工作区内文件编辑；外部路径受门控，非隔离 Shell 每次调用单独审批。 |
| 完全访问   | `alwaysAllow` | 跳过工具和路径交互审批，保留明确的安全限制。                          |

旧配置继续使用原序列化值。这些档位表达 Anya 的权限策略，并不提供 dsh 的 `read-only` / `workspace-write` / `danger-full-access` 操作系统沙箱。路径检查解析已存在的祖先路径，以识别符号链接和目录联接越界。

审批仅提供允许一次和拒绝，不再授予工具的会话或永久权限。`tool_approval.rs` 与 `path_permission.rs` 通过 `approval_wait.rs` 统一处理取消；工具和路径请求十分钟后过期。`ToolError` 区分策略拒绝与用户明确拒绝，只有后者产生用户拒绝导致停止的提示。Agent 每轮接收当前权限策略。

策略决策、审批请求和结果写入 SQLite 的 `chat_permission_events`。执行前必须完成审计写入，写入失败则拒绝执行。

## 工作台与弹窗恢复

`usePendingInteractions.ts` 按会话维护有序队列。问题、工具审批和路径审批追加到队列，不覆盖当前显示的请求；后端序列号统一不同请求类型的顺序，已完成请求 ID 阻止旧事件和快照恢复过期卡片。

`get_pending_interactions` 返回指定会话的快照，空会话 ID 返回全部会话。启动、恢复焦点和切换会话时对齐快照。后端终止路径统一发出 `interaction-resolved`，包括取消和超时，其他窗口据此移除已完成卡片；提交失败时恢复请求。

`ApprovalRequestPanel.vue` 提供共用的操作详情和纵向选项，支持方向键选择及 Enter 确认。`useSharedReviewState.ts` 通过 `anya.shared-review.v1.*` 按根会话同步图片标签、选中图片和子 Agent 查看状态。窗口尺寸与布局留在本窗口。这并不镜像全部侧栏状态；代码读取选中项仅属于点击文件的窗口。

## 读取卡片与高亮侧栏

`readCodePreview.ts` 从成功的 `read`、`read_file` 结果中提取连续编号文本，保留实际返回范围和缩进。二进制、图片和文档格式继续使用各自展示方式。`FileReadCard.vue` 显示文件名、行范围及可展开的代码编辑器；CodeMirror 提供语法高亮、原始行号和长行横向滚动。

点击文件名或预览按钮，在工作台或弹窗打开 `ReadCodeSidebar.vue`。`preview_read_code` 只接受已记录的成功读取活动 ID，不接受界面传入的任意路径。相对路径按原会话或父会话工作区解析，不回退到当前选中的工作区。磁盘读取在阻塞工作线程运行，只加载不超过 1 MiB 的普通 UTF-8 文件，拒绝含 NUL 的内容。

侧栏比较保存的读取范围与当前文件内容。一致时显示完整文件，滚动到读取位置并高亮这些行；已变化或无法加载时显示保存的片段及说明。比较仅覆盖读取范围，不保证其他位置未变化。切换会话清除代码读取选中项。预览只读，也不会把内容追加到模型上下文。

## 验证边界

针对性测试覆盖请求队列恢复、共享查看状态、读取结果解析和卡片点击。实现期间执行了前端类型检查、针对性 lint、Rust 工具测试及 Rust 编译检查。这些检查不代表原生双窗口视觉验收、真实 DeepSeek 任务质量或生产进程沙箱验证。
