# 主题编辑器

打开 **设置 → 外观 → 个性化主题库**，点击 **新建主题** 或主题卡片上的 **编辑**。

点击缩略预览中的区域，或选择区域标签，即可调整颜色和可用的形状参数。编辑器覆盖窗口、侧栏、对话顶栏与正文区、用户和助手消息、输入框、卡片、代码块、按钮及图标。消息区域支持圆角、阴影和内边距；整体设置包含界面与回复字号、消息间距，以及壁纸路径、透明度、模糊和缩放方式。

字段留空表示使用基础模式的默认值，占位内容显示当前有效值；重置箭头可以移除单项覆盖。**重置此区域** 清除该区域的自定义值。撤销和重做记录草稿变化。浅色/深色决定默认值，不限制各区域明确设置的颜色。即使对比度较低，也会保留显式颜色；对可识别的纯色组合提供提示及可选的文字对比度改善操作。

缩略预览即时更新。**在应用中预览** 在当前窗口临时应用样式参数，不写入设置或启动缓存。壁纸在缩略图中预览；此开关不会修改原生窗口材质。关闭或取消时移除临时样式。**保存并应用** 持久化主题；**另存为新主题** 生成新 ID 并保留原主题。保存失败时保留草稿，以便重试。

**JSON** 标签编辑样式参数映射，不接受完整样式表。切回可视化设置前，可先应用到预览。已知字段校验 CSS 值，并拒绝错误 JSON 或破坏声明结构的值。保留已有主题元数据、格式有效的未知参数和壁纸配置。选择壁纸只记录路径，不将图片字节写入主题。主题库原有导入/导出入口继续可用。

实现位置：`src/services/theme/editor.ts` 定义区域，`ThemeService.ts` 只补齐缺省参数，`ThemeEditor.vue` 管理草稿和预览，`settingStore.saveCustomTheme` 保存并应用主题。缩略预览用于展示外观，不模拟原生窗口材质、完整代码语法高亮及全部交互状态。
